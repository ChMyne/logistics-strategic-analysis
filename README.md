Logistics Strategic Planning and Data Exploration
Project Overview

This project focuses on strategic planning and data exploration in logistics. The objective is to analyze logistics data and identify opportunities to improve delivery performance, inventory management, and transportation efficiency.

Objectives
Analyze logistics and delivery data.
Measure important logistics KPIs.
Calculate the On-Time Delivery Rate.
Calculate Average Delivery Time.
Analyze Transportation Cost.
Identify Low Inventory Risk.
Compare delivery performance across warehouses.
Dataset

The dataset contains the following information:

Order ID
Warehouse Location
Delivery Distance
Delivery Time
Transportation Cost
Inventory Level
On-Time Delivery Status
Key Performance Indicators
1. On-Time Delivery Rate

Measures the percentage of orders delivered on time.

2. Average Delivery Time

Measures the average number of days required to deliver an order.

3. Average Transportation Cost

Measures the average transportation expense per order.

4. Low Inventory Risk Rate

Identifies the percentage of orders associated with inventory levels below the selected threshold.

The project demonstrates how logistics data can be analyzed to support strategic decision-making. The results can help identify delivery delays, transportation cost patterns, and potential inventory risks.
